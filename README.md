# Kanban Task Board

A simple and responsive Kanban Task Board designed to help users organize and track their tasks efficiently.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Set task priority: Low, Medium, High
* Set due dates
* Search tasks
* Track task counts
* Organize tasks into:

  * To Do
  * In Progress
  * Done
* Responsive and clean user interface

## Tech Stack

* HTML
* CSS
* JavaScript

## Project Structure

```text
Kanban-Task-Board/
│
├── index.html

├── script.js
└── README.md
```

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start creating and managing your tasks.
